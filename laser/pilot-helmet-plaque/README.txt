PILOT HELMET LAYERED PLAQUE  -  xTool S1 cut files
=================================================

Finished size: ~215 x 237 mm plaque (18 mm thick), ~215 x 261 mm on its stand.
Material: 3 mm basswood or birch plywood.
  - Plaque: 6 sheets (12 x 12 in / 300 x 300 mm)
  - Stand:  2 sheets (12 x 12 in)

FILES (cut in this order, back to front)
  L1_backer.svg                      black outline + tab that drops into the stand
  L2_shadow.svg                      dark layer (visor opening + all shadow gaps)
  L3_shell-and-vest.svg              helmet shell + flight vest
  L4_housing-straps-mask.svg         visor housing, straps, ear cup, mask seal, NVG housing, hose, pouches
  L5_nvg-tubes-mask-shell.svg        NVG tubes, mount shroud/bracket, mask shell, buckles, hose fitting
  L6_lenses-mount-valve.svg          lenses, NVG mount + tilt arm, knob, nose plate, valve, mask buckle
  B-A_stand_plinth-and-block.svg     stand layers B1-B4
  B-B_stand_slotted-block-and-nameplate.svg   stand layers B5-B8 (B6-B8 slotted) + nameplate
  Assembly_Guide.pdf                 piece maps, finishes, assembly steps
  preview_assembled.png / preview_layers.png

COLOUR CODE (every SVG)
  RED   #FF0000  = Cut
  BLUE  #0000FF  = Score
  BLACK fill     = Engrave
  GREEN #00E000  = optional placement guide - score lightly or delete.
                   It sits 0.8 mm inside where the next layer goes, so it ends up hidden.

XCS (xTool Creative Space)
  1. Import one SVG at a time. Files are in mm at true size - don't rescale the backer or stand.
     (To resize, scale all six plaque layers by the same % and resize the stand slot to the new tab width.)
  2. Ungroup and set the process by colour: red = Cut, blue = Score, black = Engrave, green = low-power Score.
     Start from the XCS material preset for 3 mm basswood and run a small test first.
  3. All plaque files share one canvas/origin, so pieces are already in their assembled positions.
     You can drag the small L4-L6 pieces closer together to save wood - their guides are on the layer below.
  4. The stand slot is 3.3 mm wide for 3.0 mm stock. Measure your sheet; sand the tab if it's tight.

SUGGESTED FINISH
  L1 black, L2 dark walnut, L3-L6 natural; NVG housing (4-2), eyecup and both tubes (5-3, 5-4, 5-5) in dark walnut;
  stand in dark walnut. Keep the laser-charred edges - they make the dark outlines.

ASSEMBLY
  Stain first, then glue L2 on L1, L3 inside the green guide on L2, and so on up to L6.
  Stand: B2 centred on B1, B3-B8 squared on top (slot sits closer to the BACK edge), nameplate on the front.
  Push the plaque tab into the slot with a little glue.
